# Jeebak (جيبك) — Personal finance made clear

**Personal finance · Bilingual product design · Full-stack web development**

[← Back to portfolio](../README.md)

## Product challenge

Tracking expenses is only useful when account balances, transfers, recurring bills, budgets, and different currencies add up consistently. The experience also needs to work well in both English and Arabic.

## Project overview

Jeebak is an English/Arabic personal finance web application covering transactions, accounts, budgets, savings goals, bills, and reporting.

## Selected implementation work

- React and TypeScript interface with responsive layouts and right-to-left Arabic support.
- A financial domain model designed to keep balances and summaries derived from recorded transactions.
- Multi-currency reporting that distinguishes exact values from conversions and incomplete rate information.
- Supabase and PostgreSQL integration for live accounts and authorization.
- Automated tests, configuration documentation, and separate demo/live application modes.

**Technology:** React, TypeScript, Vite, Supabase, PostgreSQL, Vitest.

## Current status

An application implementation and its documentation exist. The [project website](https://jeebak.site/) is an external link; its current deployment and feature availability should be checked independently. The source repository is private.

**What this project demonstrates:** translating complex financial requirements into a clear bilingual interface while treating correctness and data access as core product concerns.
