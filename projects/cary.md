# CARY — Connected fleet operations

**Fleet management · Operational UX · Mapping and analytics**

[← Back to portfolio](../README.md)

## Product challenge

Rental and fleet teams need a joined-up picture of reservations, vehicle movement, inspections, and unit economics. Separate spreadsheets and tools can make routine decisions slow and error-prone.

## Project overview

CARY is a fleet-operations MVP that brings booking workflows, vehicle inspection, mapped telematics simulation, and reporting into a single application.

## Selected implementation work

- Calendar-based rental reservations and vehicle handoff flows.
- A live-map interface with WebSocket-powered simulated location updates.
- Interactive damage inspection and condition reporting concepts.
- Reporting for utilization, average daily rate, revenue, and depreciation.
- A safety-gated immobilization *prototype concept*, not a deployed vehicle-control service.

**Technology:** Next.js, React, TypeScript, Prisma, Leaflet, WebSockets, Tailwind CSS.

## Current status

The project is an MVP. Real fleet integrations, vehicle control, security, and operational safety require further validation. The source repository is private.

**What this project demonstrates:** designing and integrating operational workflows with maps, domain data, and decision dashboards.
