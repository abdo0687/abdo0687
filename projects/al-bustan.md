# Al Bustan — Bilingual corporate website

**Corporate web · International business · English/Arabic UX**

[← Back to portfolio](../README.md)

## Product challenge

A company operating across multiple business divisions needs to communicate clearly with international customers. Arabic and English visitors should have coherent experiences, not just translated text.

## Project overview

The Al Bustan website project is a responsive, bilingual corporate experience designed around company information, business divisions, product information, and contextual inquiries.

## Selected implementation work

- A structured site encompassing 28 localized routes across English and Arabic.
- Right-to-left and left-to-right interface design.
- Shared visual components, responsive layouts, and navigation patterns.
- Context-aware inquiry flows and product-selection details.
- Static site generation and repeatable accessibility, layout, and interaction checks.

**Technology:** Python, HTML, CSS, JavaScript, Cloudflare Pages-oriented deployment.

## Current status

The implementation is documented in private branches. The public production domain, inquiry delivery, and release state require separate verification; no live URL is claimed here. Commercial implementation details remain private.

**What this project demonstrates:** bilingual information architecture, design systems, frontend quality, and practical delivery constraints for business websites.
